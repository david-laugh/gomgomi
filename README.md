# Gomgomi
음성 기반 AI 챗봇 애플리케이션으로, 사용자의 감정을 이해하고 공감하는 대화형 서비스를 제공합니다.
<img src="https://github.com/user-attachments/assets/9f1cc1c3-7123-4fcf-b25a-2324dc094497">

## Overview
- STT(Speech-to-Text) 기반 음성 입력 처리
- KoBART 기반 AI 챗봇 응답 생성
- TTS(Text-to-Speech)를 통한 음성 출력
- 친구처럼 친근한 대화 서비스 제공
- React Native 기반 모바일 앱 구현

## 개발 의의
- 감정 공감형 AI 챗봇 서비스 기획 및 설계
